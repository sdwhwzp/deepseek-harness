# Agent Note: 自动目标轮次保留授权主体

Status: implemented

[English](2026-09-12-goal-round-principal.md) | 中文

## 问题

已认证的 Remote 调用者可以在空会话中创建 goal。目标驱动器排入的内部用户消息缺少调用者身份，导致按账号隔离的记忆插件拒绝执行，计费也无法归属模型调用。如果从较早的会话消息查找账号，当另一个调用者恢复 goal 时还会造成归属错误。

## 决策

目标轮次驱动器在 create 和明确 resume 时同步捕获授权 principal，发生在持久化等待和独立调度之前。工具调用从 Host 专用投影读取当前发起 agent 的开放轮次归属。没有发起 agent 的 Remote 调用读取可选 Gateway 已验证的调用者。该投影折叠已提交的轮次边界，在挂载时恢复，并在轮次结束时清空；它不会同步读取任意历史，也不会向 Client 投影暴露账号数据。

每条预留消息携带捕获的 principal。接纳检查将 principal、来源和内容与预留记录比较。编辑和竞争提示保留已捕获的授权；明确 resume 会替换它。卸载和会话重启仍会停用 goal 的自动续行，因此恢复投影不会授予自动续行权限。匿名本地操作仍受支持，不会借用此前的账号。

## 考虑过的替代方案

**放宽记忆提供方的账号检查。** 这会掩盖身份丢失，却无法恢复模型调用计费或其他按账号隔离插件的隔离能力。

**从会话历史恢复最近的账号。** 已结束的轮次可能属于其他调用者，新的同步事件历史读取也违背存储演进方向。只有当前工具轮次或已验证的 Remote 调用者能为新执行授权。

**在每轮入队时读取环境中的 Gateway 调用者。** 异步检查点和独立调度可能超出变更请求的生命周期。在授权操作发生时捕获身份，可以跨越这些等待保留归属。

## 影响

驱动器依赖 Session 投影注册表以及可选 Gateway 的类型约定。归属投影只保留当前开放轮次的 principal；续行授权仍局限于当前进程。模型可见提示词和 Session 事件格式没有变化。现有记忆与计费插件收到的 principal 与普通已认证用户轮次一致。

## 测试

定向测试覆盖检查点重叠、多轮归属、驱动器重新加载后的明确恢复、工具归属，以及已认证轮次之后的匿名操作。Loader 子进程启动正式 headless profile，通过测试账号提供方调用真实 Gateway 和目标服务，验证持久化 principal 及带归属的模型请求。现有目标回放期望覆盖不变的模型可见提示和生命周期行为。
