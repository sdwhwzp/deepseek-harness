# Agent Note: 在空闲会话中隐藏保留的任务计划

Status: implemented

[English](2026-09-14-idle-todo-dock.md) | 中文

## Problem

助手可能在未写入最终任务清单的情况下结束回答。此时继续在输入框上方显示保留的清单，会让进行中的动画看起来像会话停止后仍有任务在执行。

## Decision

会话任务面板同时读取会话运行状态和任务投影，仅在运行时渲染。打开空闲会话时也隐藏面板。投影和持久事件保留原始任务状态。

## Alternatives considered

**在轮次结束时将所有任务标记为完成。** 回答完成不能证明每项计划任务都成功；这样会编造任务结果。

**在轮次结束时清空任务投影。** 历史记录消费者可能需要最后一次记录的计划。可见性属于会话任务面板，无需修改共享投影。

## Consequences

空闲会话的输入框上方不显示任务条。回到运行中的会话时，面板以折叠状态挂载。面板不提供空闲计划浏览器；历史工具记录仍可查看。组件回归覆盖清单未完成时的实时轮次结束、初始空闲渲染，以及不修改状态的重新挂载。
